### 2. 게임 시작 시 첫 힌트 자동 표시 + 덱 드로우 애니메이션

**기존 문제**: `start_game`이 `game_started`를 emit할 때 질문이 없어, 플레이어가 "다음 턴"을 눌러야만 첫 힌트가 나타남.

**서버 수정** (`server.js`)

`start_game` 핸들러에서 게임 상태 생성 직후 첫 질문을 미리 뽑아 `game_started`에 포함:

```js
// 첫 질문 미리 뽑기
const firstQuestion = gameState.questionDeck.pop();
gameState.questionDiscards.push(firstQuestion);
const firstPlayers = gameState.playerOrder.map(uid => ({ userId: uid, hand: stands[uid] || [] }));
firstPlayers.push({ userId: 'npc', hand: stands['npc'] || [] });
const firstAnswer = evaluate(firstQuestion.seq, firstPlayers, 0);

io.to(player.socketId).emit('game_started', {
    ...
    question: firstQuestion,   // ← 추가
    answer: firstAnswer,       // ← 추가
});
```

**클라이언트 수정** (`app/hooks/useGameSocket.ts`)

```ts
socket.on('game_started', (data: GameState & {
    turnDeadline?: number;
    question?: { seq: number; question: string };
    answer?: string | number;
}) => {
    setGameState(data);
    setActiveTurnId(data.currentTurn);
    if (data.question !== undefined) setCurrentQuestion(data.question);
    if (data.answer !== undefined) setCurrentAnswer(data.answer);
    if (data.turnDeadline) turnDeadlineRef.current = data.turnDeadline;
    setGamePhase('playing');  // ← 반드시 마지막에 (화면 전환 전 state 세팅)
});
```

> **포인트**: `setGamePhase('playing')`을 마지막에 호출해야 게임 화면 렌더링 시 `currentQuestion`이 이미 세팅된 상태.

**힌트덱 드로우 애니메이션** (`app/game/[id]/page.tsx`)

```
게임 시작
  └─ 0ms      : questionDeckPhase = 'shuffling'
                 → 덱 카드 3장 좌우 흔들림 + "힌트 카드 섞는 중..."
  └─ 1200ms   : questionDeckPhase = 'drawing'
                 → 맨 위 카드가 위로 날아가며 사라짐
  └─ 1650ms   : questionDeckPhase = 'visible'
                 → 질문 텍스트 fade+scale-in 등장
  └─ 2100ms   : questionDeckPhase = 'idle'
                 → 이후 turn_changed는 즉시 표시 (애니메이션 없음)
```

최초 1회만 트리거 (`firstQTriggered` ref로 중복 방지):
```tsx
useEffect(() => {
    if (gamePhase === 'playing' && currentQuestion && !firstQTriggered.current) {
        firstQTriggered.current = true;
        setQuestionDeckPhase('shuffling');
        // ...
    }
}, [gamePhase, currentQuestion]);
```

**CSS 추가** (`app/globals.css`)

| 클래스 | 설명 |
|--------|------|
| `.q-deck-card` | 덱 카드 좌우 흔들림 (0.45s alternate) |
| `.q-card-draw` | 카드 위로 날아가며 사라짐 (0.45s forwards) |

### 3. 하단 메모 드로어

게임 중 메모와 추론을 할 수 있는 슬라이드 드로어. 화면 하단에 항상 핸들이 노출되며, 클릭하면 위로 슬라이드해서 열림.

**구조**

```
[게임 화면]
──────────────── MEMO ▲ ────────────────  ← 핸들 (36px, 항상 노출)
[ 메모장 탭 | 추론표 탭]
[                                        ]
[          탭 내용 영역 (h-48)           ]
[                                        ]
```

**상태 관리**

```tsx
const [drawerOpen, setDrawerOpen]   = useState(false);
const [activeTab, setActiveTab]     = useState<'memo' | 'logic'>('memo');
const [memoText, setMemoText]       = useState(() =>
    typeof window !== 'undefined'
        ? (localStorage.getItem(`memo_${String(roomId)}`) ?? '')
        : ''
);
const [logicGrid, setLogicGrid]     = useState<boolean[][]>(() => {
    // localStorage에서 복원, 없으면 3×7 전부 true
    ...
    return Array.from({ length: 3 }, () => Array(7).fill(true));
});
```

**localStorage 자동 저장**: `roomId`를 키로 사용해 새로고침 후에도 메모 유지.

```tsx
useEffect(() => {
    localStorage.setItem(`memo_${String(roomId)}`, memoText);
}, [memoText]);

useEffect(() => {
    localStorage.setItem(`logic_${String(roomId)}`, JSON.stringify(logicGrid));
}, [logicGrid]);
```

**탭 1 — 메모장**

- `<textarea>` 자유 입력, 배경 투명, `font-mono`

**탭 2 — 추론표**

내 타일 3자리 × 숫자 1~7 격자. 클릭하면 `○`(가능) ↔ `✕`(불가) 토글.

```tsx
// 셀 클릭 핸들러
onClick={() => setLogicGrid(prev =>
    prev.map((c, ci) => ci === col
        ? c.map((v, ri) => ri === row ? !v : v)
        : c
    )
)}
```

- `○` 상태: 어두운 배경 + 금색 테두리
- `✕` 상태: 빨간 배경 + 빨간 테두리 + line-through 스타일
- 우하단 "초기화" 버튼으로 전체 리셋

**레이아웃 겹침 방지**

드로어 핸들(36px)이 게임 콘텐츠를 가리지 않도록 메인 컨테이너 하단 패딩 조정:

```tsx
// 기존
className="... p-4 ..."
// 수정
className="... pt-4 px-4 pb-12 ..."
```
