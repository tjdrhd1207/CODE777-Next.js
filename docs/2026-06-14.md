### 1. rooms 페이지 실시간 방 목록 갱신 (소켓 Push 방식)

**변경 전 (Pull 방식)**
- 클라이언트가 `room_list`를 emit해서 요청해야만 응답 → polling 필요

**변경 후 (Push 방식)**
- 누군가 입장/퇴장할 때 서버가 모든 클라이언트에게 자동 broadcast

```js
// server.js
function broadcastRoomList() {
    const roomList = Array.from(rooms.entries()).map(([roomId, players]) => ({
        roomId,
        playerCount: players.length,
    }));
    io.emit('room_list_updated', roomList); // 전체에게 push
}
// join_room, leaveRoom에서 호출
```

```ts
// rooms/page.tsx
socket.on('room_list_updated', (updatedList) => {
    updatedList.forEach(({ roomId, playerCount }) => {
        updatePlayerCount(Number(roomId), playerCount);
    });
});
```

**핵심**: DB는 방 목록 초기 로드용, 소켓은 인원수 실시간 갱신용으로 역할 분리

### 2. 한글 아이디 `??` 버그 수정

**원인**: MSSQL에서 `sql.VarChar`는 유니코드 미지원 → 한글이 `??`로 저장됨

**해결**: `sql.NVarChar`로 변경 (N = National = 유니코드)

```ts
// Before
.input('username', sql.VarChar, username)

// After
.input('username', sql.NVarChar, username)
```

**추가**: SQL 리터럴에도 `N` 접두사 필요
```sql
-- 잘못된 방법
UPDATE users SET id = '재민' WHERE user_seq = 2002;

-- 올바른 방법
UPDATE users SET id = N'재민' WHERE user_seq = 2002;
```

### 4. server.js — start_game 이벤트 추가

**핵심 설계: 플레이어마다 다른 payload 전송**

```js
// 본인 타일은 절대 본인에게 보내지 않음
players.forEach(player => {
    const visibleStands = {};
    Object.entries(stands).forEach(([uid, tiles]) => {
        if (uid !== player.userId) {
            visibleStands[uid] = tiles; // 상대방 + NPC만 전송
        }
    });
    io.to(player.socketId).emit('game_started', { visibleStands, ... });
});
```

**게임 상태 구조 (gameStates Map)**
```
stands       - 각 플레이어 + NPC 받침대 타일
tileDeck     - 남은 타일 더미
tileDiscards - 버린 타일
questionDeck - 질문 카드 더미 (23장 셔플)
scores       - 플레이어별 점수
currentTurnIndex / playerOrder - 턴 관리
```

**서버 검증**: 방장만 시작 가능 (프론트 버튼 숨김만으론 불충분 — 콘솔에서 직접 emit 가능)

## 배운 개념

### useRef vs useState 선택 기준
- **"이 값이 바뀌면 화면도 바뀌어야 하나?"**
  - YES → `useState`
  - NO → `useRef` (소켓, 타이머 등 내부 리소스)

### 모듈 레벨 변수 vs useRef
- 모듈 레벨 `let socket`은 컴포넌트 인스턴스 간 공유됨 → 충돌 위험
- `useRef`는 컴포넌트 인스턴스에 종속 → 각자 독립적
