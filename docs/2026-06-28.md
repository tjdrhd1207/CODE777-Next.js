## 오늘 한 것

### 1. Rooms 테이블 playerCount 필드 추가

DB에 현재 인원수를 저장하는 컬럼 추가. 기존에는 in-memory `rooms` Map에서만 관리하고 소켓으로만 실시간 동기화했으나, DB에도 저장해 초기 로딩 시 정확한 인원수 제공.

```sql
ALTER TABLE Rooms ADD playerCount INT NOT NULL DEFAULT 0;
ALTER TABLE Rooms ALTER COLUMN hostId NVARCHAR(100); -- VarChar → NVarChar (한글 깨짐 수정)
```

**영향받은 파일**

| 파일 | 변경 내용 |
|------|-----------|
| `server.js` `join_room` | `UPDATE Rooms SET playerCount = @playerCount` (신규 입장 시) |
| `server.js` `leaveRoom` | `UPDATE Rooms SET playerCount = @playerCount` (퇴장 시), 0이면 `DELETE` |
| `app/api/rooms/route.ts` | SELECT에 `playerCount` 추가, `WHERE playerCount > 0` 필터 |
| `app/store/useRoomStore.ts` | `fetchRooms`에서 `playerCount → players` 매핑 |

### 3. 게임 종료 시 방 정리 (leaveRoom 기반)

`game_over` 이벤트 발생 직후 방을 즉시 삭제하지 않고, 플레이어가 로비로 돌아갈 때(`leave_room`) 마지막 플레이어가 나가는 시점에 삭제하도록 설계.

`leaveRoom` 함수에 `gameStates.delete(roomId)` 추가 — 기존에 in-memory 누수 있었음:

```js
if (players.length === 0) {
    rooms.delete(roomId);
    gameStates.delete(roomId);  // ← 추가
    // DELETE FROM Rooms ...
}
```

### 4. join_room 레이스 컨디션 수정

**문제**: `rooms_changed` 이벤트가 DB playerCount 업데이트보다 먼저 발사되어, 로비가 `fetchRooms` 해도 아직 `playerCount = 0`인 방이 조회되지 않는 문제.

**수정** (`server.js`): 핸들러를 `async`로 바꾸고 DB 업데이트를 `await` 후 이벤트 발사.

```js
// Before: fire-and-forget
poolPromise.then(pool => { pool.request()...query(...); });
io.emit('rooms_changed');  // DB 완료 전에 먼저 발사

// After: await 후 발사
await pool.request()...query(...);
io.emit('rooms_changed');  // DB 완료 보장
```

또한 재연결 시 `players` 배열에 중복 push하던 버그도 함께 수정:

```js
const existing = players.find(p => p.userId === userId);
if (existing) {
    existing.socketId = socket.id;  // socketId만 갱신
    return;  // 새 entry 추가 안 함
}
```

### 5. server.js DB 연결 타이밍 수정

**문제**: `import { sql, poolPromise } from './lib/db.js'`가 모듈 최상단(static import)에 있어 Next.js가 `.env` 파일을 로드하기 전에 DB 연결을 시도 → `DB_USER = undefined` → "Login failed for user ''" 에러.

**수정**: static import를 제거하고 `app.prepare()` 완료 후 dynamic import로 변경.

```js
// Before (top of file)
import { sql, poolPromise } from './lib/db.js';

// After (inside app.prepare().then())
app.prepare().then(async () => {
    const { sql, poolPromise } = await import('./lib/db.js');
    // env 변수가 이미 로드된 상태에서 연결
    ...
});
```

### 6. 서버 시작 시 stale 방 초기화

서버가 재시작되면 in-memory `rooms` Map은 비워지지만 DB 레코드는 남아 playerCount가 부정확해지는 문제. 서버 시작 시 Rooms 테이블 전체 삭제.

```js
poolPromise.then(pool => {
    pool.request().query('DELETE FROM Rooms');
});
```

### 8. 메모 드로어 탭2 — Code 777 질문 체크리스트

기존 탭2(3×7 타일 추론 그리드)를 Code 777 실제 질문지 기반 체크리스트로 교체.

**질문 유형별 입력 방식**

| 질문 | 입력 |
|------|------|
| Q1~Q11 (몇 개?) | `−` `[값]` `+` 버튼 |
| Q12~Q23 (어느 것이 더?) | `[A]` `[=]` `[B]` 토글 버튼 |

**기능**
- 현재 진행 중인 질문(`currentQuestion.seq` 매칭 시) → 해당 행 노란 하이라이트
- 입력값 `localStorage`에 자동 저장 (`quiz_${roomId}` 키)
- 숫자 `−` 버튼으로 0 이하로 내리면 답 초기화 (`—` 표시)
- A/B/= 버튼은 같은 버튼 재클릭 시 해제
