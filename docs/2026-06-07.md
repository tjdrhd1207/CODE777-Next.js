## 오늘 한 것

### 버그 수정 — 방 나가기 버튼 TypeError

**증상**
```
Uncaught TypeError: Cannot read properties of undefined (reading 'emit')
at onClick (app/game/[id]/page.tsx:83:45)
```

**원인**

`socket`을 모듈 레벨 변수로 선언했기 때문에 `useEffect` 실행 전엔 `undefined`.

```ts
// 문제 코드
let socket: Socket; // 선언만 하면 undefined
```

**해결**

`useRef`로 교체해 컴포넌트 인스턴스에 종속시키고, `?.` 옵셔널 체이닝으로 안전하게 호출.

```ts
const socketRef = useRef<Socket | null>(null);

useEffect(() => {
    const socket = io('http://localhost:3000');
    socketRef.current = socket;
    // ...
    return () => {
        socket.disconnect();
        socketRef.current = null;
    };
}, [roomId, userId]);

// 사용 시
socketRef.current?.emit('leave_room', { roomId, userId });
```

## 배운 것

### useRef vs useState

| | `useRef` | `useState` |
|---|---|---|
| 값이 바뀔 때 | 리렌더링 안 함 | 리렌더링 함 |
| 용도 | 소켓, 타이머 등 내부 리소스 | 화면에 표시되는 데이터 |

**선택 기준**: "이 값이 바뀌면 화면도 바뀌어야 하나?"
- YES → `useState`
- NO → `useRef`

### 컴포넌트 인스턴스 종속

같은 컴포넌트가 여러 개 렌더링될 때(예: 채팅방 목록) 모듈 레벨 변수를 쓰면 인스턴스 간 데이터가 공유되어 충돌 발생.

```tsx
// 각 채팅방 항목이 독립적인 인스턴스
{chatRooms.map((room) => (
    <ChatRoomItem key={room.id} room={room} />
))}
```

- 화면에 표시되는 값(읽지 않은 수, 마지막 메시지) → `useState`
- 내부 리소스(소켓 연결) → `useRef`
